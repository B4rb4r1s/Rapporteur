# Контракты «Репортёра»

Общий язык данных команд 1 и 2 (ADR-007): Pydantic-модели, JSON Schema, TS-типы, примеры. Версия — в [VERSION](VERSION), по semver: несовместимое изменение повышает старшую цифру.

## Команды

Нужны только Docker и make, всё выполняется в контейнерах.

| Команда | Что делает |
| --- | --- |
| `make generate` | JSON Schema в `schema/` и TS-типы в `ts/index.ts` из моделей |
| `make test` | примеры, отказы, правила |
| `make lint` | ruff, mypy, tsc |
| `make check-generated` | падает, если `schema/` и `ts/` отстали от моделей |
| `make lock` | обновить `uv.lock` после правки `pyproject.toml` |

Подключение: `rapporteur_contracts` ставится как пакет из `contracts/` (`pip install ./contracts`), фронтенд импортирует типы из `contracts/ts/index.ts`.

## Что где

| Модуль | Содержимое |
| --- | --- |
| `entities.py` | конференция, секция, доклад, файл, сегмент, профиль модели, задача |
| `fragments.py` | фрагменты в двух слоях и пакет фрагментов доклада |
| `claims.py` | ответы LLM (`FactsDraft`, `SummaryDraft`), утверждения, сводка, `TalkSummaryBundle` |
| `reports.py` | выборка, вход сборки, выдача справки |
| `artifacts.py` | артефакты этапов, `StageInputs`, `StageOutput` |
| `graph.py` | граф этапов (ADR-009) |
| `registry.py` | `conference.yaml` (spec §7.4) |
| `api.py`, `enums.py` | формы ответов API, перечисления, переходы статусов |

## Слои фрагментов

Кэш этапов общий между конференциями, а ревизии и правки принадлежат конференции (ADR-008):

1. Этап возвращает `FragmentDraft`: файл и локатор, без UUID и меток.
2. Воркер создаёт `SourceFragment` и `FragmentRevision`.
3. Перед этапами сводки воркер собирает `TalkFragmentPack`: только фрагменты этого доклада, с метками. Другого пространства поиска цитат нет.

## Правила вне JSON Schema

JSON Schema описывает форму. Связи между объектами проверяют валидаторы моделей, поэтому объект нужно строить через Pydantic. Главное правило для воркера: перед публикацией сводки построить `TalkSummaryBundle(pack=..., summary=...)`. Он отклоняет чужую ревизию, неизвестную метку и `span` за пределами текста.

Все отказы с кодами ошибок перечислены в [examples/invalid.yaml](examples/invalid.yaml). Коды стабильны, на них можно опираться.

`span` считается в кодовых точках: в Python это обычные индексы строки, в JavaScript перед подсветкой их нужно перевести в смещения UTF-16.

`claim_ids` в сводке — короткие ключи `c1`, `c2`, а не UUID: их видит модель.

## Как менять

Контракт меняется только PR с одобрением обеих команд; до подключения команды 2 — по ADR-011. В том же PR: правка моделей, `make generate`, примеры, запись в `VERSION`.

Новая верхнеуровневая модель добавляется в `PUBLIC_MODELS` и получает пример `examples/valid/<Модель>--<описание>.json`: тест не пропустит её без примера.

Материалы конференций в примеры не копируются: весь текст здесь вымышленный (spec §16).
