## Статусы

- **Предложено** — решение описано, ждёт замеров или одобрения.
- **Принято** — действует; спецификация ему соответствует.
- **Заменено ADR-NNN** — больше не действует, оставлено для истории.

## Шаблон

Новый ADR получает следующий свободный номер и имя файла `ADR-NNN-короткое-имя.md`.

```markdown
# ADR-NNN. Название

- Статус: Предложено
- Дата: ГГГГ-ММ-ДД
- Ведёт: К1 · лид
- Связано: spec §…, ADR-…

## Контекст

Что заставляет принять решение: ограничения, требования, факты замеров.

## Варианты

1. …
2. …

## Решение

Что выбрано и почему.

## Последствия

Что становится проще, что сложнее, что нужно сделать.

## Когда пересмотреть

Условия, при которых решение надо открыть заново.
```
