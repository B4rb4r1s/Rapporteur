# ADR-001. Стек и закреплённые версии

- Статус: Принято; точные версии закрепляются в Ф0 (P0-02, P0-03)
- Дата: 2026-10-27
- Ведёт: К1 · лид
- Связано: spec §8, §9, ADR-004, ADR-005

## Контекст

Приложение работает в изолированной сети на одном сервере с двумя A100. Backend, конвейер и воркеры пишутся на Python; нужны LLM-сервер с structured outputs, разбор pptx и pdf, рендер слайдов, работа с аудио и сборка DOCX. Исходные ТЗ расходились во фронтенде (React SPA против Next.js) и в инфраструктуре (ADR-004, ADR-005).

## Варианты

1. **Фронтенд.** Next.js с отдельным Node-рантаймом или SPA на React + Vite, собранная в статику.
2. **PDF.** PyMuPDF (AGPL или коммерческая лицензия) или pypdfium2 (Apache-2.0 / BSD-3) для текста и рендера.
3. **LLM-сервер.** vLLM или другой сервер с OpenAI-совместимым API.

## Решение

| Слой | Выбор |
| --- | --- |
| Язык и рантайм | Python 3.12; менеджер зависимостей с lock-файлом (рекомендуется uv) |
| Backend | FastAPI, Pydantic v2, SQLAlchemy 2, Alembic |
| БД и очередь | PostgreSQL (ADR-004) |
| LLM и VLM | vLLM с OpenAI-совместимым API и structured outputs, отдельный контейнер |
| Презентации | python-pptx; pypdfium2 для pdf; LibreOffice headless для pptx → pdf |
| Аудио и речь | ffmpeg, Silero VAD, адаптеры ASR (ADR-002) |
| Текст | rapidfuzz, razdel, pymorphy3 |
| Справка | docxtpl, LibreOffice headless для DOCX → PDF |
| Фронтенд | React, TypeScript, Vite, wavesurfer.js; статика отдаётся контейнером `web` |
| Проверки | ruff, mypy, pytest; eslint, tsc, vitest |
| Развёртывание | Docker, docker compose, NVIDIA Container Toolkit |

- Next.js не используется: SSR внутреннему инструменту не нужен, а лишний Node-рантайм усложняет офлайн-поставку.
- PyMuPDF не используется, пока лицензия AGPL не согласована отдельно; pypdfium2 покрывает текст и рендер.
- vLLM живёт в отдельном контейнере, чтобы его зависимости CUDA не конфликтовали с библиотеками ASR.
- Все версии библиотек, digest образов и ревизии весов закрепляются; тег `latest` запрещён.

## Последствия

- Один язык для backend, конвейера и воркеров; общие контракты на Pydantic (ADR-007).
- Фронтенд собирается в образ `web`, отдельного сервиса для него нет.
- В Ф0 нужно заполнить таблицу закреплённых версий в `docs/benchmarks/` и лицензии в `docs/licenses.md`.

## Когда пересмотреть

- Закреплённая версия vLLM не поддерживает выбранную модель или structured outputs вместе с режимом рассуждения.
- Качество извлечения текста pypdfium2 на эталоне заметно хуже альтернатив.
