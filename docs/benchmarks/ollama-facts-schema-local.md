# Схема фактов в Ollama: локальная проверка

Дата: 2026-11-01. Проверка механизма для ADR-010, а не замер P0-03: модель не целевая, карта не серверная, запросы шли по одному.

## Стенд

| Что | Значение |
| --- | --- |
| Машина | WSL2, NVIDIA GeForce RTX 3060, 12 ГБ |
| Образ | `ollama/ollama:0.40.13` (`sha256:b2f0122c…`), для сравнения `0.30.11` (`sha256:c484b703…`) |
| Запуск | `deploy/ollama/compose.yaml`: внешний каталог моделей, внутренняя сеть, `OLLAMA_NO_CLOUD=1` |
| Модели | `qwen3.5:9b` (6,6 ГБ, 100% GPU, контекст 8192), `qwen3.5:0.8b-q8_0` (1,0 ГБ) |
| Схема | `FactsDraft` из `contracts/`: `$ref`, `pattern`, nullable, кириллические enum |
| Запрос | `/api/chat`, вымышленный доклад из пяти слайдов и одной заметки, `temperature=0.1`, `num_predict=12000`, разные `seed` |

Команда:

```bash
docker run --rm --network rapporteur-ollama_inference -e MODEL=qwen3.5:9b -e RUNS=6 -e NUM_PREDICT=12000 -v "$PWD/deploy/ollama:/smoke:ro" rapporteur-contracts-dev:local python /smoke/smoke_facts.py
```

«Форма» — ответ прошёл JSON Schema. «Полностью» — прошёл ещё и валидаторы Pydantic.

## Результаты на 0.40.13

| Модель | Режим | Форма | Полностью | Время ответа | Скорость |
| --- | --- | --- | --- | --- | --- |
| `qwen3.5:9b` | с рассуждением | 6 из 6 | 5 из 6 | 74–119 с | ≈ 49 ток/с |
| `qwen3.5:9b` | без рассуждения | 6 из 6 | 6 из 6 | ≈ 13 с | ≈ 47 ток/с |
| `qwen3.5:0.8b-q8_0` | без рассуждения, `num_predict=4000` | 2 из 8 | 0 из 8 | 9–27 с | ≈ 149 ток/с |

## Что это значит

- Схема соблюдается и с рассуждением, и без него. Сообщение о нестрогой схеме для Qwen 3.5 на этой версии не подтвердилось.
- Отказ «полностью» один: `conclusions_reason_mismatch`. Грамматика проверяет только форму, связь между полями ловит валидатор, и такой ответ уходит на повтор.
- Рассуждение стоит дорого: при той же скорости ответ занимает в 6–9 раз больше времени. На коротком докладе это примерно 5 тыс. токенов (оценка: скорость × время), что близко к резерву 8K из spec §6.7. На длинном докладе резерв надо измерить.
- `qwen3.5:0.8b-q8_0` не годится для шага А: в 6 из 8 ответов она повторяла элементы массивов до лимита, а с рассуждением не успевала закончить его за 12 000 токенов.

## Версия 0.30.11

Не годится. При `think=false` поле `format` не применялось вовсе: простая схема, `format=json` и `FactsDraft` дали один и тот же ответ без JSON. Поэтому образ закреплён на 0.40.13, а тег `latest` на машине разработки оказался на четыре месяца старше.

## Что осталось проверить на сервере (P0-03)

Целевая модель `qwen3.6:27b-bf16`, две карты, контекст 32K, 8 параллельных запросов, реальные доклады. Этот замер ничего не говорит о пропускной способности на A100.
