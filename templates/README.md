# Бланки справки

Бланк — каталог с DOCX и `variables.yaml` (spec §6.9). Его можно заменить без правки кода: код проверяет, что бланк использует только описанные переменные, а при сборке — что заданы все обязательные.

## Как править бланк

DOCX открывается в Word или LibreOffice. Плейсхолдеры — разметка Jinja, которую понимает [docxtpl](https://docxtpl.readthedocs.io/):

- `{{ переменная }}` подставляет значение;
- `{%p if … %}`, `{%p for … %}`, `{%p endif %}`, `{%p endfor %}` стоят в отдельных абзацах и при сборке удаляются вместе с ними;
- внутри одного тега формат текста не меняется: иначе Word разрежет тег на части и бланк не соберётся.

Word меняет прямые кавычки на типографские, docxtpl внутри тегов возвращает их обратно.

## Фильтры

| Фильтр | Пример | Результат |
| --- | --- | --- |
| `период` | `{{ period \| период }}` | «22 октября 2026 г.», «20–22 октября 2026 г.», «30 октября – 1 ноября 2026 г.», «30 декабря 2026 г. – 2 января 2027 г.» |
| `согласовать` | `{{ talks_count \| согласовать("доклад", глагол="заслушан") }}` | «заслушан 1 доклад», «заслушано 3 доклада», «заслушан 21 доклад», «заслушано 25 докладов» |
| | `{{ speakers_count \| согласовать("докладчик", падеж="род") }}` | «1 докладчика», «5 докладчиков»: для оборотов «от … докладчиков» |
| `ёлочки` | `{{ title \| ёлочки }}` | «Название»; кавычки внутри становятся „лапками“ |
| `типографика` | `{{ talk.summary \| типографика }}` | неразрывные пробелы в «23 %», «2026 г.», «4 узла», «№ 5» |

Даты, числа и неразрывные пробелы между числом и словом ставят фильтры, поэтому строка не разорвётся между «2026» и «г.». Падежи для `согласовать`: `им`, `род`, `дат`, `вин`, `твор`, `пред`; глагол согласуется только в именительном.

Названия городов и организаций не склоняются: их вводят в нужной форме или пишут бланк без склонения («Место проведения: г. Казань»).

Период всегда кончается сокращением «г.», поэтому после него в конце предложения точку не ставят: иначе получится «2026 г..».

## starter

Стартовый бланк, пока нет образцов настоящих справок. Текст бланка:

```
СПРАВКА
по итогам конференции {{ title | ёлочки }}

Конференция проходила {{ period | период }}
{%p if place %}
Место проведения: {{ place }}.
{%p endif %}
В рамках конференции {{ talks_count | согласовать("доклад", глагол="заслушан") }}, с докладами {{ speakers_count | согласовать("докладчик", глагол="выступил") }}.

Краткое содержание докладов
{%p for talk in talks %}
{{ loop.index }}. {{ talk.title | ёлочки }} ({{ talk.speakers | join(", ") }})
{{ talk.summary | типографика }}
{%p if talk.conclusions %}
Основные выводы:
{%p for conclusion in talk.conclusions %}
– {{ conclusion | типографика }}
{%p endfor %}
{%p endif %}
{%p endfor %}
```

Оформление: A4, поля 30/15/20/20 мм, Times New Roman 14 пт, отступ первой строки 1,25 см. Как выглядит собранная справка, показывает образец `tests/fixtures/starter_expected.txt`.
