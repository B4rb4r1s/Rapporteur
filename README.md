# Репортёр

Локальное приложение, которое по материалам научной конференции (презентации, записи выступлений, заметки слушателей) готовит справку: краткое описание каждого доклада, выводы и параметры конференции. Работает без внешних API.

- [Спецификация](docs/spec.md)
- [Бэклог Ф0–Ф1](docs/backlog.md)
- [Архитектурные решения](docs/adr/README.md)

## Что нужно

Docker с плагином compose и make. Python, Node и библиотеки на машину ставить не нужно: все проверки и сборки идут в контейнерах.

## Команды

| Команда | Что делает |
| --- | --- |
| `make check` | все проверки всех каталогов: линтеры, типы, тесты, актуальность сгенерированных контрактов, сборка фронтенда |
| `make lint` | только линтеры и проверка типов |
| `make test` | только тесты |
| `make -C backend run` | backend на http://127.0.0.1:8000, проверка — `/health` |
| `make -C pipeline run STAGE=slides INPUT=$PWD/data` | этап конвейера на папке с материалами; результаты в `pipeline/.rapporteur-data/`, вне git. `STAGE` — `slides` или `notes` |

У каждого каталога с кодом свой `Makefile` с теми же целями и `make lock` для обновления lock-файла.

## Перед слиянием в main

CI нет (ADR-011). Перед слиянием в `main` автор запускает `make check` на актуальной ветке и пишет результат в описании PR. Если меняются контракты или ADR, а команда 2 ещё не подключилась, изменение записывается в раздел «Ждёт просмотра командой 2» в [backlog.md](docs/backlog.md).

## Каталоги

| Каталог | Что внутри |
| --- | --- |
| `contracts/` | контракты данных: Pydantic-модели, JSON Schema, TS-типы, примеры |
| `pipeline/` | этапы конвейера без веба и БД, CLI `rapporteur run`; сейчас разбор презентаций и заметок, грамматика и рендер бланка справки |
| `templates/` | бланки справки: DOCX и `variables.yaml`, правила в [templates/README.md](templates/README.md) |
| `backend/` | FastAPI |
| `frontend/` | React + Vite + TypeScript |
| `deploy/` | compose-сервисы, сейчас Ollama |
| `docs/` | спецификация, бэклог, ADR, замеры |

Каталоги из spec §8.4 появляются по мере появления кода. `data/` и `docs/SoW/` в git не входят.
